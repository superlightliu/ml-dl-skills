# 从代码疑问返回概念

以下问题组用于检索官方教材，不是目录镜像。

| 当前卡点 | 检索词 | 先定位的对象 | 最小核对 |
|---|---|---|---|
| 一行张量代码看不懂 | data manipulation, broadcasting | 每个轴的语义 | 写出输入与输出 shape |
| 梯度为零、重复累积或缺失 | automatic differentiation, backpropagation | 计算图与梯度生命周期 | 跟踪一次清零、反传、更新 |
| 损失与正确率不一致 | softmax, cross-entropy, evaluation | logits、标签与聚合分母 | 用自设两样本手算统计口径 |
| 卷积输出尺寸不符 | padding, stride, channels | 空间轴与通道轴 | 手算一个小输入的输出尺寸 |
| 序列或注意力看到了未来 | sequence, attention, masking | Q/K/V 来源与可见位置 | 绘制长度为 3 的可见性表 |
| 优化表现难以解释 | optimization, initialization | 目标缩放、步长与初始化 | 改一个因素并提出观察预期 |
| 教材函数似乎不存在 | documentation, modules, utilities | 框架 API 或教材辅助函数 | 查定义和版本，不先安装一套新环境 |
| 下游任务运行但评价无效 | computer vision, NLP, recommender, evaluation | 划分单位与目标指标 | 找出预处理、调参和测试的边界 |

## 片段对照表

回答涉及多个实现时，可用下面的四列对齐，避免只比较相似的函数名。

| 数学对象 | 当前代码中的对象 | 形状或约定 | 需要查阅的定义 |
|---|---|---|---|
| 输入与标签 | 使用学习者实际变量名 | 批次轴、特征轴、编码 | 数据加载或预处理 |
| 预测或 logits | 使用实际前向输出 | 值域、类别轴 | 最后层和输出函数 |
| 单样本损失 | 使用实际 loss 表达式 | reduction、mask | 损失 API 和包装函数 |
| 参数更新 | 使用实际 optimizer | 清梯度、步长、状态 | 训练循环 |
| 评价结果 | 使用实际 metric | 累计方式、样本权重 | 评价循环 |

## 原创诊断与常见陷阱

- 自设大小不同的两个批次，比较“先算批次平均再平均”和“按样本累计再平均”的统计差异。
- 让学习者预测一个带可学习参数的小层在训练模式与评价模式下哪些行为可能变化，再查看实际使用的模块。
- 自设一个形状可广播但语义错误的加法，要求同时写出形状合法性和轴含义。
- 区分自动求导跟踪与模块的 train/eval 状态；检查它们各自控制的行为。
- 片段能执行只说明该执行路径通过；正确目标、合法划分和可靠泛化仍需独立检查。

没有运行时使用“推演”或“预计”描述结果，不补写训练日志或性能分数。
