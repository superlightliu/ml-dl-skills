# 机器学习数学阅读导航

围绕当前公式或疑问补足数学条件。只问一个问题时，不强制补完整门数学课。

## 开始阅读

- 先识别学习者卡在符号、运算、推导还是应用。已有公式、维度和目标充分就直接开始；缺一项关键条件时只补问那一项。
- 查 [topic-route.md](references/topic-route.md) 选择主题和一个诊断动作；查 [source-guide.md](references/source-guide.md) 取得官方入口及版本核对方法。
- 用户给了合法可读的本地教材，可核对其实际版本；没有教材时从官方入口查相关内容。不假定任何固定磁盘、文件或页码存在。未取得原文时，可讲通用数学并注明尚未核对该书表述，不编造定位。

## 推导工作流

1. 列对象表：变量含义、形状、定义域，以及样本按行还是按列。用不同记号区分向量、样本集合与随机变量。
2. 写目标关系及前提。检查秩、可逆性、可微性、积分存在性或约束条件中哪些是本步真正需要的。
3. 对学习者出错的一步展开推导。每次转置、求逆、换元、交换积分与求导时，说明依据；不要以维度相符代替证明。
4. 设计独立的小矩阵或一维例子，让学习者先预测。需要数值核对时，先检查已有运行环境，只运行与问题相关的短计算。
5. 用退化情形检验结论，如重复列、零向量、奇异协方差或边界点。数值成立只能支持该例，不能替代一般证明。

回答保留必要英文关键词，明确区分书中定义、当前假设与独立推导。只有实际打开并核对后才引用章、节或页；印刷页和 PDF 物理页分开记录。

## 反馈与互补技能

学习者想练习时先给诊断题，再按作答逐级提示；明确要求完整推导时直接展开。反馈指向具体错误和一次迁移检查，不根据“读完”判断掌握。

- 回归或分类的建模与验证问题，按需使用 [ml-foundations](../ml-foundations/SKILL.md)。
- 概率模型、估计与决策问题，按需使用 [probabilistic-ml-intro](../probabilistic-ml-intro/SKILL.md)。
- 反向传播在网络中的使用，按需使用 [dl-foundations](../dl-foundations/SKILL.md)。
- 多周计划和学习记录，按需使用 [ml-dl-study-coach](../ml-dl-study-coach/SKILL.md)。

这些是可选互补入口；未安装时继续当前数学问题。这里的工作流不要求新增依赖或运行教材完整代码。
