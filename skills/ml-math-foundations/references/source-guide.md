# 原书入口与引用方法

Marc Peter Deisenroth、A. Aldo Faisal、Cheng Soon Ong，Mathematics for Machine Learning，Cambridge University Press，2020。书目信息与官方阅读入口见 [作者网站](https://mml-book.github.io/)。

官方站点分别提供与印刷版对应的 PDF、持续修订的 PDF、勘误和学习资源。根据学习者所用文件确认版本；出版年份不能代替在线文件日期，不能沿用另一版的页码。

## 定位方法

1. 将中文疑问转换为少量检索词，例如 projection、matrix decomposition、vector calculus、change of variables 或 constrained optimization。
2. 从作者站点进入相关内容，先核对符号定义及前提，再追查公式。阅读只扩展到回答当前问题需要的范围。
3. 若用户的公式与原书不同，先比较样本方向、分母、转置和符号约定；不能仅凭外观差异判定错误。
4. 引用已读取的标题与官方链接；只有核对原件后才加页码。找不到具体位置时明确记录“原书位置未核对”。

本技能的文件是独立撰写的学习工作流与问题分类，不包含原书正文、图表、练习解答或章节翻译。原书及官方资源的权利归各自权利人；本技能的 MIT 许可不适用于外链原书。需阅读完整推导或原图时访问官方资源，不把原书复制进技能包。
