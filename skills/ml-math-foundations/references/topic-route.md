# 按学习障碍选择阅读动作

以下按学习者的问题分类，不对应原书完整目录。检索词用于进入官方资源；具体章号和页码以实际查看的版本为准。

| 学习障碍 | 官方资源检索词 | 先做的诊断 | 推导时特别核对 |
|---|---|---|---|
| 矩阵式不知如何相乘 | linear algebra, rank | 写出每个对象的形状 | 样本方向、线性映射的定义域和值域 |
| 投影或距离解释不清 | projection, inner product | 说明投影到哪个子空间 | 所用内积、正交条件、基是否归一 |
| SVD、特征分解混淆 | matrix decomposition | 判断矩阵是否方阵、对称 | 分解存在条件、非零奇异值、秩 |
| 梯度式与代码不一致 | vector calculus, chain rule | 画输入到标量目标的依赖关系 | Jacobian 布局、广播、求和约定 |
| 概率密度变换出错 | probability, change of variables | 指明变量支持集和映射 | 可逆分支、Jacobian 绝对值、归一化 |
| 优化步骤会算但不知为何 | continuous optimization | 写目标、约束与候选点 | 局部与全局、驻点与最优点、步长条件 |
| 学过公式却看不懂模型 | linear regression, PCA, mixture, SVM | 指明正在最小化或最大化的量 | 参数、隐变量、数据及正则项分别是谁 |

## 原创小例的构造

- 形状：自设 3 个样本、2 个特征的矩阵，分别写“样本按行”和“样本按列”的预测式，解释两式如何对应。不要直接照搬教材例子的数值。
- 投影：先选两条正交方向，再把其中一条换成与另一条平行，要求说明哪些计算步骤失去条件。
- 梯度：自设只有两个参数的标量函数，手算一个方向导数，再比较解析梯度的内积。若使用有限差分，改变步长以观察舍入和截断影响。
- 约束：给一个一维凸目标及闭区间，让学习者比较无约束驻点和区间端点；由此检查是否遗漏可行性。

## 常见误判与追问

| 误判 | 下一步追问 |
|---|---|
| 形状能乘就证明公式正确 | 这个式子表示哪两个映射的复合？ |
| 不可逆就无法做最小二乘 | 需要唯一参数，还是只需要最优预测？ |
| 零梯度必然是极小值 | 能构造局部极大或鞍点吗？ |
| 概率密度大于 1 不合法 | 哪个积分必须等于 1？ |
| PCA 不必说明中心化 | 这里希望解释的是离原点的能量还是围绕均值的变化？ |

答后以改变一个条件的迁移题检验理解；反馈保留学习者实际回答，不补写未发生的学习记录。
