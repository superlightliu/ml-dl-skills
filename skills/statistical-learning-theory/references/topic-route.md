# 从统计问题进入阅读

这些是原创问题组，不重现原书章节结构。

| 当前疑问 | 检索词 | 优先写清 | 常见误区 |
|---|---|---|---|
| 最优预测的含义是什么 | decision theory, regression function | 损失、条件分布、决策空间 | 忽略损失改变会改变最优动作 |
| 收缩、筛选与稳定性怎样权衡 | ridge, lasso, least angle regression | 完整惩罚目标与尺度 | 系数为零就等于因果无关 |
| 非线性如何受控制 | spline, smoothing, RKHS | 函数空间、平滑约束 | 只看拟合曲线不看自由度与选择 |
| 模型评估为何偏乐观 | model assessment, cross-validation | 整个选择流程及嵌套关系 | 只交叉验证最后一步模型 |
| 集成方法为什么不同 | boosting, random forests, additive models | 基学习器、聚合与训练依赖 | 把所有集成都称作降低同一种误差 |
| 核方法与间隔如何对齐 | support vector machines, kernels | 特征映射、间隔与惩罚参数 | 不对照目标就比较 C 与 lambda |
| 无监督结构是否可信 | clustering, manifold, latent variables | 相似性、保留结构、评价目标 | 一个可视化就证明真实分组 |
| 高维下证据怎样解释 | high-dimensional, multiple testing, FDR | 维数、检验族、错误率 | 把 FDR 当成单个结论为假的概率 |

## 对照两种方法时

先固定观测、任务和评价，再分别填写：

- 表示：模型允许什么形式的函数？
- 控制：通过什么约束、惩罚、平滑或数据结构限制拟合？
- 计算：求解的目标与实际算法是什么，是否有近似？
- 选择：哪些超参数经由什么数据选择？
- 结论：回答预测、变量恢复、统计检验还是因果问题？

## 原创诊断动作

- 自设两列几乎重复的特征，要求学习者预测最小二乘与有惩罚估计的稳定性差别，再检查所需条件。
- 给同一损失的“求和版”和“平均版”，要求推出使两个惩罚目标等价的参数缩放。
- 画出先特征筛选、再交叉验证的流程，要求指出筛选在哪一层需要重做。
- 自设多次尝试模型后只报告最佳结果的情景，要求解释为什么一次验证误差不再是独立评价。

检索不到确切定理时保留未核对状态，不用相近术语补写定理名称、常数或证明出处。
