# 按目标抽取诊断题

诊断用于选起点，不是排名。一次给一道与当前目标相关的题，先不展示标准答案；用户只问具体问题时无需先做本表全部题目。

| 能力 | 原创题目 | 观察什么 | 不足时的下一步 |
|---|---|---|---|
| Python | 对列表 [3, 7, 11, 15] 取中间两个数，写出其平均值的表达式并预测结果 | 切片边界、运算、能否说明代码 | 用更短列表演示索引，再做一个变式 |
| 数据形状 | 80 条样本每条有 6 个特征，单标签分类的 X 和 y 通常各是什么形状 | 样本轴、特征轴、标签对应 | 画两行小表并手工配对 |
| 统计与评价 | 训练误差很低，为什么还要保留未参与选择的数据 | 记忆与泛化、评价对象 | 对比练过的题与新题，不先引入复杂定理 |
| 划分 | 同一设备的连续读数用于预测未来故障，随机按行切分可能有什么问题 | 组、时间、预测时可见信息 | 画一条时间线并标记观测可用时刻 |
| 分类指标 | 200 条记录只有 8 条正例，全部预测负类的 accuracy 是多少；它能否满足漏检代价高的目标 | 基线、类别不平衡、错误代价 | 让学习者填混淆矩阵 |
| 深度学习 | 输入 [B, 4] 经线性层到 3 类，logits 和类别索引标签各是什么形状 | 形状与输出含义 | 转深度学习基础中的形状练习 |

已观察到的困难只决定相关补课，不推出学习者需要重学全部数学或编程。自述背景与客观作答分开记录。完整答案若由用户直接索要，可以给出，但应再用不同变式评估独立能力。
