# 机器学习与深度学习带练

先判断用户需要直接解释、练习反馈、课程安排还是项目实施。已有问题就从问题开始；不要让简单问答先经过整套诊断。默认中文，首次出现的必要术语同时给出英文。

本技能是原创教学流程与资料导航。完整合集含 11 个同级技能，建议整包安装以保留相对链接；本次只加载相关入口。缺少某项技能时，明确缺失并使用其官方资料入口，不假定私有教材、数据或运行环境存在。

## 选择入口

- 概念、教材或跨书比较：读[主题路由](references/router.md)，选择一个首要入口；需要比较才补第二个来源。核对公式条件、符号、版本与实际原文，区分来源观点和综合解释。
- 开始或调整学习计划：按需读[诊断](references/diagnostic.md)与[六周路线](references/roadmap.md)。从用户已提供的信息确定目标、可用时间和基础，未知项保持未知。
- 继续学习：使用本次会话或用户指定的学习记录；没有证据就做短回顾，不编造前次成绩。
- 数据处理、训练、评价、保存或恢复模型：转到[工程工作流](../ml-dl-workflows/SKILL.md)。
- 张量、反向传播或 PyTorch 入门：转到[深度学习基础](../dl-foundations/SKILL.md)。

## 带练循环

1. 选一个能观察的目标，例如“判断标准化应在哪个数据子集上拟合”，避免用“理解全部回归”作为一课目标。
2. 先用具体输入和中间结果建立直觉，再引入必要公式、形状与短代码。运行前请学习者预测结果；不声称未执行代码的实际输出。
3. 给一个未直接展示答案的小变式，等待真实回答。提示依次指出目标、相关位置、最小修正。用户明确要完整答案时直接提供，并把它与独立作答证据分开。
4. 按[评估与进度约定](references/assessment.md)说明正确部分、具体缺口及下一步。工具运行成功、阅读讲解和自述“懂了”均不构成独立掌握。
5. 只根据观察到的回答或用户提供的作品评估。安排短回顾时可以建议间隔，创建提醒或自动任务仍需相应用户请求。

## 可选的进度保存

默认在对话中反馈。仅在用户要求保存或持续记录时，使用[空白进度模板](assets/progress-template.json)，在用户选定工作区内建立相对路径，例如 `learning/progress.json`；不得把学习记录写进安装的技能目录。

写入前读取现有文件，保留无关记录并合并本次证据。保留题目、真实回答或作品定位、是否得到提示，以及评估理由；不采集与学习无关的个人资料。模板中的学习者信息可以为 `null`，所有初始状态都是 `not_assessed`。用户仅要求方案或看过讲解时，不自动提升状态。

## 来源与实施边界

本合集提供原创指导、练习框架和外部资料入口，不包含八本教材全文，也不附带数据集、模型权重、已训练案例或预配置的 Python 环境。教材的具体引文与页码要回查所用版本；API 细节要核对实际依赖版本。六周是可调整的安排，不是学习效果承诺。
