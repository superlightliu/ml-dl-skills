# 概念与练习设计

本表是原创带练框架。选择一行完成一个短循环即可，不把它当作教材章节摘要。具体公式和原章按[来源路由](sources.md)查阅。

| 主题 | 从什么具体问题开始 | 要显式说明的条件 | 独立变式 |
|---|---|---|---|
| 张量与广播 | 两条样本各含 4 个特征，逐特征减去均值后形状如何变化 | 样本轴、特征轴、尾轴广播规则；可广播不代表含义正确 | 把偏置从 [4] 改为 [2, 1]，解释两种减法各代表什么 |
| 梯度与更新 | 一个标量参数改变时，平方误差朝哪个方向变化 | 梯度是局部变化率；backward 计算并累加梯度，optimizer 执行更新 | 移动清零梯度的位置，预测连续两次 backward 的差异 |
| logits 与分类损失 | 三类输出 [1, -2, 0] 表达什么，怎样与正确类别关联 | logits 不是概率；类别索引与软目标两种损失接口分开 | 改变类别数或标签编码，指出需要同步修改的接口 |
| MLP 与泛化 | 为何连续两层线性映射之间加入非线性 | 表达能力与能否训练、能否泛化是不同问题 | 保持数据划分，改变宽度并设计如何判断过拟合 |
| CNN | 一个小卷积核在图像上共享权重时，输出位置怎样形成 | 通道、步长、填充、核尺寸、局部连接与共享参数 | 改步长或输入分辨率，先算输出形状再验证 |
| 注意力 | 一个 query 怎样用 key 的分数汇总 value | Q/K 内维相容；softmax 的键轴、缩放与 mask 含义明确 | 让一个位置不可见，说明应改分数还是最终输出 |

## 推演到代码

先给 2–3 个样本或几个标量，要求学习者画出输入到损失的依赖。只实现当前概念需要的运算；可运行环境和依赖缺失时用手算或伪代码。调用模型用 `model(x)`，并按实际库版本核对接口，不从教材辅助类名推断 PyTorch 内置行为。

比较模型时保留相同数据、划分和选择规则。一个更低的训练损失不能证明泛化改善；一个小实验也不能证明 CNN 总优于 MLP。注意力权重是模型内部计算量，不能直接作为因果解释或预测可靠性的证明。

## 反馈模板

先指出学习者哪一步推理成立，再定位一个决定性差异，例如“标签里放了 1 到 3，而输出列按 0 到 2 编号”。请其修正并预测后果，再检查实际结果。对回答完整且独立的主题，追加一个边界反例；对困难主题，缩小输入或降低抽象程度，不直接要求重学整套前置课程。
