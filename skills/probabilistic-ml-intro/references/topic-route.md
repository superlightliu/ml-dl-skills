# 按概率问题选择阅读

以下分类依据学习问题，不复制原书目录。

| 学习问题 | 检索词 | 首先写下的对象 | 关键自查 |
|---|---|---|---|
| 条件概率和密度混淆 | conditional probability, density | 事件、随机变量、支持 | 条件固定了什么、对谁归一化 |
| 估计量与后验分不清 | maximum likelihood, Bayesian inference | 数据、参数、先验 | 参数是优化变量还是积分变量 |
| 为什么同一概率对应不同动作 | decision theory, loss | 可选动作及错误代价 | 概率估计与决策规则是否分开 |
| 交叉熵和 KL 方向混乱 | information theory, KL divergence | 两个分布和期望所属分布 | 支持包含、有限性、方向 |
| 线性模型何时合理 | linear models, GLM | 条件均值或条件分布 | 链接函数、噪声和尺度假设 |
| 核、近邻或树如何比较 | kernel, nearest neighbors, trees | 相似性、结构和损失 | 比较是否使用同一评价协议 |
| 低维表示或聚类代表什么 | dimensionality reduction, clustering | 保留的结构及潜变量 | 几何结构与语义是否被混同 |
| 少标签、推荐或图任务怎样定义 | semi-supervised, recommendation, graph | 可观测关系及预测单位 | 标签和交互信息的可见边界 |

## 对照符号的最小记录

- 对象：是样本中的一个数、随机变量、参数，还是一个分布？
- 条件：哪些量固定，哪些量需积分、求和或优化？
- 支持：允许出现哪些值，密度或质量函数相对什么测度？
- 目标：估计、预测、决策分别使用什么评价？
- 计算：精确求解、数值近似和抽样误差分别有哪些？

## 原创练习构造

1. 给一个两种状态、两种观测的自设概率表，先核对总和，再求条件概率。改变先验，要求解释后验为何变化。
2. 在相同预测概率下设置两种错误代价，要求比较动作；不要默认阈值总为 0.5。
3. 自设一个只有几个结果的离散分布，让学习者指出某个 KL 方向何时因支持问题变为无穷。
4. 给同一组点设计两个不同距离度量，要求解释近邻或聚类结果变化是否意味着算法出错。

## 需要制止的概念跳跃

似然高不等于模型真实；后验窄不等于模型正确；优化器的随机波动不等于预测不确定性；相关或潜在分组不自动具有因果含义。要求学习者补出缺失的条件或独立评价，而不是只背一句结论。
