# 按学习问题选择路线

这些是独立设计的学习入口，不是原书目录或章摘要。英文词用于在官方教材中定位。

| 当前问题 | 检索词 | 最小诊断动作 | 易漏条件 |
|---|---|---|---|
| 特征、标签和预测目标不清楚 | statistical learning, supervised learning | 为一条样本写预测时可见的信息 | 观测单位与信息时间 |
| 指标很好但换数据失效 | resampling, cross-validation | 画出预处理与数据划分顺序 | 主体重叠、时间泄漏、测试集调参 |
| 回归式会写但不懂系数 | linear regression, regularization | 改一个特征单位后预测系数如何变化 | 尺度、共线性、截距与惩罚 |
| 分类准确率掩盖错误 | classification, logistic regression | 在自设混淆矩阵上比较两种错误 | 正类编码、阈值和类别比例 |
| 曲线或树越复杂越好？ | splines, additive models, trees, boosting | 比较训练与验证误差的可能走向 | 模型容量和选择过程 |
| PCA 或聚类结果难解释 | principal components, clustering | 预测改变单位后的距离或主方向 | 中心化、尺度和评价目的 |
| 观察期不一致或检验很多次 | censoring, survival, multiple testing | 指出删失记录与未发生事件的区别，或定义一组检验 | 删失假设、检验族、错误率含义 |

## 六次短练习的可选顺序

已有基础可直接跳到对应问题，不把这一路线当成原书章节结构。

1. 为一个自设表格标出样本、特征、标签和预测时间。
2. 给一个包含重复主体的数据情景，解释按行随机划分的风险。
3. 用少量自设点比较恒定预测、直线和有惩罚的直线。
4. 构造类别比例悬殊的混淆矩阵，选择适合任务的指标并说明代价。
5. 比较浅树和深树的训练表现与训练外表现，先提出可检验假设。
6. 对同一小点集改变一列的单位，解释距离、聚类和主成分的变化。

每次只引入本次必要概念；原创数值明确是假设，不能写成真实业务结果。教学记录只使用学习者实际作答及实际运行证据。

## 追问模板

- “模型用了未来信息”具体是哪一列、哪一步、哪个时间点？
- 两个方法差的是模型，还是预处理、划分或评价口径？
- 如果删除一个隐含假设，结论仍成立吗？
- 若只看训练误差，哪些问题无法被发现？
