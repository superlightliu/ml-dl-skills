# 机器学习基础阅读与带练

以一个能检查的学习目标开始，例如“说明为什么先划分再标准化”。已有目标或作答就直接沿用，不要求重复背景。

查 [topic-route.md](references/topic-route.md) 选择问题入口和诊断动作；查 [source-guide.md](references/source-guide.md) 取得官方阅读入口。只读回答当前问题需要的材料。用户没有本地教材时使用官方资源；无法取得原文时明确说明未核对该书表述，不虚构页码、公式编号或已读记录。

## 带练与建模工作流

1. 明确要预测什么、每条记录代表谁、预测发生在什么时候，以及什么错误更重要。区分预测、解释、聚类与统计检验。
2. 先检查训练、验证、测试的职责与划分单位。时间依赖按时间考虑，同一主体重复记录按主体考虑；预处理、筛选和调参必须留在相应训练边界内。
3. 选一个简单基线，解释输入、输出、损失、参数和指标。分类先确认正类编码与阈值，回归先确认目标单位。
4. 对一个疑问给一个原创小例。需要代码时检查当前环境并使用最少依赖，不把教材输出当作本机结果。
5. 让学习者预测改变一个条件后的结果，例如缩放特征、改正类、增加树深或改变验证划分；根据其回答定位误区。
6. 比较方法时保持数据划分和指标口径一致。最终测试结果不能反复用于选择模型；预测关联也不能直接解释为因果。

以中文解释并保留必要英文检索词。书中结论、额外假设、独立推导和实际运行结果分别表述。学习者要练习时先给问题和分级提示；明确要解法时直接提供，不把听过讲解记为独立掌握。只有实际执行后才报告计算或训练结果。
