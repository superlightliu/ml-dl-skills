# 按理论障碍选择阅读

下表按问题组织，不是原书目录。具体公式编号与页码需返回官方 HTML 核对。

| 当前障碍 | 检索词 | 核心诊断动作 |
|---|---|---|
| 线性代数与概率符号混乱 | linear algebra, probability, information | 写形状、随机对象、条件与支持 |
| 数学等价但实现溢出 | numerical computation, conditioning | 指出计算顺序、有限精度和尺度 |
| 网络训练的导数不清楚 | feedforward networks, backpropagation | 分别画前向依赖与反向贡献 |
| 正则和优化效果混淆 | regularization, optimization | 判断改变的是目标、训练算法还是数据 |
| 卷积或循环结构难理解 | convolution, recurrent networks | 追踪共享参数、感受范围或时间展开 |
| 重构目标与表征目标不同 | autoencoders, representation learning | 写要保留的信息和下游评价 |
| 概率图和潜变量难处理 | graphical models, inference | 先写联合分解再确认未知量 |
| 采样或生成模型的难点不清楚 | Monte Carlo, partition function, approximate inference | 区分期望、归一化与后验的计算任务 |

## 原创自查例

- 给出三个相差很大的自设 logits，要求解释直接指数运算的数值风险，再推导共同平移对 softmax 概率的影响。
- 构造一个有两条路径共享同一参数的小网络，手算该参数对标量目标的贡献。
- 自设一个重构目标，使某种无关信息容易被保留，要求说明低重构误差为何不直接保证下游任务有效。
- 设计两个变量的有限联合分布，分别计算边缘概率、条件概率和一个期望，说明每项计算的对象不同。
- 自设短状态链，先验证目标分布是否不变，再讨论从特定起点得到的有限样本能说明什么。

## 常见误读与应对

| 误读 | 阅读时补做的动作 |
|---|---|
| 通用逼近意味着训练可达 | 找出表示能力的量词与优化所需额外条件 |
| 反传正确就说明模型正确 | 分别核对损失、数据过程和评价目标 |
| 无偏估计量一定误差小 | 同时检查方差和计算预算 |
| MCMC 有不变分布就能放心取短链 | 检查初态、混合和相关性诊断 |
| ELBO 优化就获得精确后验 | 说明近似族、目标差距和优化误差 |
| 经典教材的实验结论就是当前最佳实践 | 标出原结论年代，并为当前问题另找来源 |

反馈只针对实际作答或可核验结果，不把完成一项例子描述为已掌握整个主题。
