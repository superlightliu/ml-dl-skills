# 阅读问题分类

以下是原创问题路线。先用关键词在官方资源中找到内容，再核对当前版本；不从表格推断章号或公式编号。

| 学习问题 | 检索词 | 建议先检查什么 |
|---|---|---|
| 多层网络究竟增加了什么 | shallow networks, deep networks, activation | 哪一步引入非线性、哪些参数在变化 |
| 损失为何这样定义 | loss functions, likelihood | 输出支持、观测假设与损失聚合 |
| 导数链在哪里断了 | backpropagation, computation graph | 每条依赖路径及共享参数的贡献 |
| 训练差或验证差如何区分 | optimization, regularization, generalization | 训练协议、数据划分、模型容量各自的证据 |
| 卷积、残差、注意力为什么有用 | convolution, residual, attention | 共享关系、信息可见范围、序列位置 |
| 图数据为何不能按普通表格处理 | graph neural networks | 节点与边、置换、消息聚合的语义 |
| 生成模型如何比较 | generative models, latent variables, diffusion | 能计算什么、能采样什么、评价什么 |
| 技术指标之外还需考虑什么 | ethics, bias | 使用场景、受影响群体、评价遗漏及不确定性 |

## 原创诊断动作

- 自设两个线性变换，要求学习者说明中间没有非线性时是否能合并；随后只改一个激活函数。
- 设计一个参数被使用两次的小计算图，分别标出两条梯度路径，再解释为何贡献需要累加。
- 给长度为 3 的符号序列，要求画出预测下一个符号时允许查看的位置；据此核对注意力掩码。
- 对一个只产生两种结果的玩具生成器，分别提出质量问题和覆盖问题；避免将某个视觉样本当总体证据。

## 常见误区与后续动作

| 误区 | 后续动作 |
|---|---|
| 模型表示能力强就一定能训练好 | 分别给表示、优化和验证提出一个可观察指标 |
| 反向传播就是参数更新 | 在计算图导数之后单独写优化器的更新规则 |
| 损失下降等于训练外可靠 | 说明评价样本如何得到及与训练数据的关系 |
| 注意力权重直接证明因果解释 | 先定义解释目标，再说明额外证据需要什么 |
| 一个逼真样本证明生成器覆盖充分 | 构造遗漏一种结果但样本仍逼真的反例 |

需要精确图示、完整证明或书中习题时返回官方资源。练习答案按学习者请求提供，不生成整套原书答案替代材料。
