# 六类实施路线

这些路线说明需要什么输入、怎样建立公平对照，以及应保存什么。它们不是打包好的案例。只为选中的路线准备依赖；不要为了阅读本文件安装全部软件。

| 路线 | 适用输入 | 起步方案 | 首要检查 |
|---|---|---|---|
| 表格 Pipeline | 明确行单位、字段类型、标签的表格 | 简单统计基线，再用预处理加线性模型的 Pipeline | 所有拟合步骤位于训练或交叉验证训练折内 |
| XGBoost | 有非线性与交互可能的表格任务 | 与线性/浅树基线比较，以开发数据选参数和轮次 | 预测使用最佳轮还是完整模型要一致 |
| 不平衡分类 | 正类定义明确，错误代价与类比例可说明 | 原始分布基线、类别权重，必要时训练内重采样 | 验证/测试保留目标分布；阈值提前固定 |
| 小型图像分类 | 图像、标签、样本或主体 ID | 简单分类器或小 MLP，再与小 CNN 公平比较 | 相同划分和预算；预处理、类别与检查点一致 |
| 文本检索 | 文档 ID、查询、相关集合与语言范围 | BM25 与精确稠密检索，再按规模考虑 ANN | 金标冻结、查询隔离、分数和概率区别 |
| 时间序列 | 有时间戳、采样频率、目标与已知协变量的序列 | naive/季节 naive，再用适合结构的预测模型 | 每个预测起点只能使用当时可见的数据 |

## 表格与不平衡分类

先检查重复行、同主体跨集合、标签产生时间与缺失机制，再选择预处理。交叉验证应包住整个拟合流程，不能先全量标准化或选特征再交叉验证。重采样只改变训练折，避免合成样本的信息进入验证或测试。说明重采样方法对距离、类别和最小样本数的要求。

分类评价同时给出正类、阈值、混淆矩阵与类比例。PR/average precision 会受类比例影响；不要把不同测试分布上的数值直接排名。选阈值使用独立开发数据或训练内方法；最终测试评估冻结策略。

## XGBoost 与图像任务

XGBoost 的训练记录应保留被监控验证集、指标、方向和选定轮次，具体对齐方法见[轮次范围](xgboost.md)。不能因为配置了早停，就声称训练确实提前终止。

图像划分按真实推广对象决定；同主体的近似图像不应随意散落两侧。比较模型时统一数据、增强、预算和选检查点规则。先明确需要推理恢复还是继续训练，再确定状态保存范围，见[恢复层次](verification.md)。

## 检索与时序

检索先规定文档单位、切块与去重规则，明确一个查询是否有多个相关文档。语言与业务分布影响模型选择，不默认英文模型已适合其他语言。模型下载、语料上传及外部服务调用服从当前用户授权。

时序使用滚动起点或其他与上线条件一致的回测。缺失值处理不得借助未来观测；未来协变量只有在预测时确实已知才可使用。分别记录预测跨度、每个起点的误差、聚合权重及基线；预测区间的覆盖表现只支持测试范围与模型假设，不等于未来保证。
