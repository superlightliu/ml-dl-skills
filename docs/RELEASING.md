# 版本发布

1. 更新 CHANGELOG.md、plugin.json 与 .codex-plugin/plugin.json 中的同一版本号。
2. 运行结构校验、测试和一次隔离目录安装。核对同级引用与空白模板。
3. 检查只包含可公开的原创文件，确认没有教材正文、私有进度、令牌、本机路径或运行环境。
4. 复核文档中的命令、功能边界和来源。结构验证不代表所有客户端或教学行为均已验证。
5. 提交到 GitHub，等待实际 CI 结果；失败时保留日志并修复。
6. 为同一提交建立 vX.Y.Z 标签和 Release，发布变更说明。不要重写已发布标签；改正用新版本。

GitHub 仓库和 Release 是本项目分发入口。需要申请第三方平台公开目录时，应另按该平台当前要求提交，不能把仓库创建成功描述为官方目录审核通过。
